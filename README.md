# 台风模拟器 Typhoon Simulator

**版本 1.2.0** · Godot 4.7.2 · 由 Scratch / TurboWarp 工程移植重制

一个把「西北太平洋台风」做成可玩模拟器的游戏：你自己画台风路径，然后看它在真实的海温场、
风切变、地形和季节里怎么发展、怎么登陆、怎么消散。

---

## 一、这是什么

原版是一个 Scratch / TurboWarp 作品，本工程用 Godot 4 重写了全部渲染与交互，
**强度计算部分逐行对照原始积木逻辑移植**（可在 `docs/参考_伪代码_*.md` 里逐条核对），
然后在几个原版明显不合理的地方做了有依据的修正（见下文「与原版的差异」）。

地图范围：**90°E ~ 190°E，10°S ~ 70°N**（西北太平洋 + 东亚 + 东南亚 + 澳洲北部）。

## 二、玩法

### 启动

1. 双击运行（或从 Godot 编辑器打开工程运行）
2. 标题画面选**模拟模式**和是否开启**风季模式**
3. 进游戏后点侧栏的「**＋ 添加台风**」，或**直接在地图上左键点击**开始标路径点

### 标路径

- **左键**在地图上依次点出路径点
- **右键**取消最后一个点
- 路径点之间**每段代表 6 小时的移动**
- 点够了按侧栏的「**★ 投放台风**」开始模拟

> 路径点画得越密，台风走得越慢；画得越稀，走得越快。
> 现实台风移速约 15~25 km/h，对应每 6 小时移动约 0.9°~1.4°。

### 两种模式

| 模式 | 说明 |
|---|---|
| **手动模式** | 你画路径，台风照你画的走。可以反复投放多次。 |
| **自动模式** | 台风沿内置路径自动生成与移动。 |
| *电影模式* | 未开放。 |

**风季模式**：只模拟 **1月1日 → 12月30日**（一年，每月固定 30 天）。
结束后结算并把本季最强台风写入 **ACE 排行榜**。此模式下不能改日期（防作弊）。
不开风季模式则无限模拟，一年结束后回到 1月1日。

### 侧栏

- **实时状态**：强度、气压、分类、海温、风切变、眼壁置换阶段、ACE 累计
- **暂停模拟 / 继续**
- **单位切换**：kt / m/s / km/h
- **调整日期**（风季模式下禁用）

### 台风分类

| 分类 | 风速 |
|---|---|
| 热带低压 TD | < 30 kt |
| 热带风暴 TS | 30 ~ 33 kt（**< 33 kt 不命名**） |
| C1 | 34 ~ 63 kt |
| C2 | 64 ~ 82 kt |
| C3 | 83 ~ 95 kt |
| C4 | 96 ~ 112 kt |
| C5 | ≥ 113 kt |

> 风速没有硬上限——原版存档里出现过 503 kt。靠「软自限」遏制，不是硬顶。

## 三、模拟了什么

强度每帧按原版公式推进，主要因子：

| 机制 | 说明 |
|---|---|
| **海温效应** | 海温越高增强越快。26.5℃ 是基准，低于它开始减弱。 |
| **风切变** | 垂直风切变越大越抑制增强。随纬度自动变化（越往高纬越大）。 |
| **科氏力** | 赤道附近（±2° 内）无法维持，会被削弱。 |
| **季节** | 8 月最强、2 月最弱；海温有 ±1.5℃ 的季节增幅。 |
| **MPI 软自限（B′）** | 强度越接近「该海温的理论上限」，增强越慢，但永不归零。 |
| **眼壁置换（ERC）** | 超过 100 kt 后周期性发生：外眼墙生成 → 内眼墙崩溃（强度掉一截）→ 新眼墙接管（反弹）。风切变太大 / 海温太低时**置换会失败**，结构崩溃、掉得更狠。 |
| **冷水坑** | 强台风会把自己下方的海温搅冷，形成「冷尾流」；离开后缓慢恢复。 |
| **陆地减弱** | 登陆后**指数式**衰减趋向约 27 kt 的背景强度。**地形越崎岖衰减越快**（平地 / 1000m 山区 / 2500m 高山三档）。 |
| **浅海热库上限** | 近岸浅海暖水层薄、热库小，**撑不起超强台风**：水深 <100m 上限 140 kt、<50m 上限 110 kt、<20m 上限 80 kt。 |
| **变性** | 高纬海温低、风切变大时逐渐转为温带气旋，强度进一步下降。 |

## 四、看海温（调试）

按 **`T`** 打开「海温查看模式」：192 个海区全部按温度上色，**鼠标探针**跟随显示所指格子的
详细数据（行列、编号、经纬、海温、季节增幅、冷水坑状态、地形判定）。再按 `T` 关闭。

### 全部按键

| 键 | 作用 |
|---|---|
| `T` | 海温查看模式（色块 + 探针） |
| `G` | 网格线（核对格子与地图是否对齐） |
| `R` | 重新采样陆地掩膜 |
| `F3` | 调试信息显示 |
| `F4` | 掩膜可视化循环：陆地(红) → 1000m 山区(青) → 2500m 山区(黄) → 水深<100m(绿) → <50m(橙) → <20m(紫) |
| `F5` | 高亮游戏实际判定的陆地格子 |
| `F6` | 调试面板（可查看/直接修改运算用的海温、气压、台风数值） |
| `Esc` | 暂停菜单 |

## 五、配置文件

**注意：这类参数和玩家设置是分开的两套。**
玩家设置（音量、全屏、方案）存在**游戏目录**的 `settings.cfg`，游戏内改就行。

设计参数在游戏目录的 `config/` 下，**改完重启游戏生效**：

### `config/simulation.cfg`

```ini
[timing]
physics_ticks_per_second=30        ; 物理帧率（参考工程的真实速率是 30）
seconds_per_day=4.0                ; 1 模拟日 = 4 真实秒
seconds_per_day_idle=0.5           ; 无台风时的空闲加速
cooling_apply_interval_seconds=0.5 ; 冷水坑降温间隔
shear_walk_interval_seconds=0.1    ; 风切变随机游走间隔

[ocean]
land_sst=26.5                      ; 台风在陆地上时的「有效海温」（越低减弱越快）
shelf_cap_100m=140                 ; 浅海强度上限
shelf_cap_50m=110
shelf_cap_20m=80
shelf_excess_pull=0.004            ; 超过上限后的回落速度
land_decay_bg_kt=26.7              ; 陆地衰减趋向的背景强度
land_decay_tau_plain=22            ; 陆地衰减时间尺度 τ（小时，越小掉得越快）
land_decay_tau_mountain=12
land_decay_tau_mountain2500=9
```

### `config/sst.txt`

192 个海区的基准海温，按 **12 行 × 16 列**排（行优先，`对应海区 = 行号×16 + 列号 + 1`）。
忽略 `#` 注释和空行，空白分隔的数字都算。**改这里不用动代码。**

> 导出成 exe 之后想调参：把 `simulation.cfg` / `sst.txt` 复制到 **exe 同目录**，会覆盖内置的那份。

## 六、与原版的差异

移植时刻意修正的地方（都有依据，不是随手改）：

1. **物理帧率 100 → 30 Hz**。原版用 `wait(0.01)` 推进强度循环，名义 100 Hz，
   但 Scratch / TurboWarp 默认只有 30 fps，实际约 1 帧 = **30 次/秒**。
   按 100 Hz 照搬会把每模拟日的增量放大 3.33 倍。
2. **海温效应的两个断崖**（27.5℃、30.0℃）改成平滑门限。原版是分段 `×0.8 / ×0.3 / ×0.8`，
   导致「近岸 30℃ 比外海 29.5℃ 强 2.7 倍」这个反物理的凹槽。
3. **陆地减弱改成指数式**。原版是线性 `ΔKt -= 0.5`，越弱掉得越快、一路崩到 0；
   现实是指数衰减、趋于约 27 kt 的背景强度。
4. **陆地上的海温继承问题**。原版用「海温 ≤10℃」编码陆地格，但只填了 50°N 以北的三行，
   中国 / 中南半岛 / 印度的陆地格仍是 27~30℃ 的暖海值 → 陆地上照样增强。
   本工程改为按像素级陆地掩膜判定，并提供 `land_sst` 参数。
5. **新增浅海热库上限**。原版完全没有水深概念，近岸浅海可以像远洋一样爆到 180 kt。
6. **地图经纬映射修正**。早期版本纬度映射小了 25%，导致赤道判错、科氏力反向等等。

## 七、技术信息

- **引擎**：Godot 4.7.2（GL Compatibility 渲染后端）
- **地图**：1772×1418 像素，100°×80°，约 **6.3 km/像素**
- **海区网格**：16×12 = 192 格，每格约 700 km（仅用于海温/气压场渲染和记账）
- **地形判定**：陆地 / 山区 / 水深全部走**逐像素**采样掩膜（比 700 km 的格子细 110 倍）
- **字体**：**Noto Sans SC Regular**（SIL OFL 1.1）随包分发，在 `project.godot` 的
  `gui/theme/custom_font` 里设为全局默认字体 —— 导出后的 Windows / Web 版**不再依赖系统字体**
  （以前网页版没有系统字体，中文全是豆腐块）
- **存档**：ACE 排行榜在**游戏目录** `saves/ace_records.json`

## 十、1.1.0 新增

### 模拟设置（游戏内：暂停菜单 → 设置 → 模拟设置）

**注意分清楚两样东西：**

| | 在哪 | 有什么 |
|---|---|---|
| **模式选项** | 标题画面点「模拟单台」时弹出的面板 | 模拟模式（手动/自动/电影）+ 风季模式 |
| **模拟设置** | **游戏内**暂停菜单 → 设置 → 第 3 个标签页 | 下面这些可调参数 |

两者**互相独立**：模式只在开局时选，进游戏后不能再改；模拟设置则在游戏进行中随时可调。

| 项 | 说明 | 什么时候可调 |
|---|---|---|
| 单位设置 | kt / m/s / km/h | **一直可调** |
| 平均海温 | **20~100℃**，整体影响强弱 | 非风季模式可调 |
| 季节海温增幅 | 0~4℃，季节摆幅 | 非风季模式可调 |
| 记录热带扰动和低压 | <30 kt 的扰动也列进台风列表 | 非风季模式可调 |
| 最佳路径数据集 | 见下 | 非风季模式可调 |

> **风季模式是"比赛"模式**：除了单位设置，其他调数值的选项全部禁用（防作弊），
> 最佳路径**强制开启**且不能关。
>
> 台风能"读到"的海温上限是 **100℃**（`Const.SST_READ_CAP`），
> 防止把平均海温拉满之后 MPI 软限算出荒谬的数值。

### 最佳路径数据集

勾上「最佳路径数据集」并选好导出目录（默认 `<游戏目录>/BestTrack`）后，
游戏会记录**此后新诞生的每一个台风**（正在跑的那个不补记）。

- 游戏内一年结束（12月30日）时写出 `Best Track <系统时间YYMMDD>-<游戏内年份>.txt`
- 格式参照 **CMA 最佳路径数据集**（每 6 小时一个点，含头记录 + 数据记录）
- 文件开头有**中英双语声明**：本文件由模拟器生成，不是真实观测资料
- 跨年台风**按生成年份归档，不拆分**
- 填不了的字段：`EEEE`（我国编号）写 `0000`；`OWD` 写 `-`；`F` 终结记录目前统一 `0`

### 超顶超增长抑制

超过 **170 kt** 之后，正增长会额外除以 `1 + (Kt−170)/170`：
增长逐级变慢，但**始终为正**——仍然能慢慢爬到 300~400 kt，不会硬顶。
（可在 `config/simulation.cfg` 的 `[intensity]` 段调）

## 十一、导出与本地预览

### Windows 版

导出预设 `Windows Desktop`（exe + .pck）。先在 Godot 里导出，再把 `游戏导出/` 里的 zip 发出去即可。

### 网页版（Web）

导出预设 `Web`，产物是 `Typhoon1.1.1.html` / `.js` / `.wasm` / `.pck`。

> ⚠ **不能直接双击 `.html` 打开**。Godot 4 的网页版用了多线程（`SharedArrayBuffer`），
> 浏览器要求服务器返回 `Cross-Origin-Opener-Policy` / `Cross-Origin-Embedder-Policy` 两个响应头；
> `file://` 和 `python -m http.server` 都**不会**返回它们，直接打开一定白屏/报错。
> 用仓库里的 `游戏导出/serve_web.py` 起本地服务：

```bat
python serve_web.py -d <导出目录>            :: 默认端口 8000，并自动打开浏览器
python serve_web.py -d <导出目录> -p 8080    :: 指定端口
python serve_web.py -d <导出目录> --no-browser
```

然后访问 `http://localhost:8000/Typhoon1.1.1.html`。

- 只能用 `http://localhost` / `http://127.0.0.1` 访问；换成局域网 IP（`http://192.168.x.x`）时浏览器
  不认为它是安全上下文，`SharedArrayBuffer` 依然不可用（浏览器规则，不是脚本问题）。
- 字体已随包：**Noto Sans SC Regular**（SIL OFL 1.1），网页版不依赖系统字体；
  粗体用 `FontVariation` 的 `variation_embolden` 合成（见 `assets/theme/main_theme.tres`）。

## 十二、1.2.0 新增

### 最佳路径导出：格式可选（NOAA / CMA）

暂停菜单 → 设置 → **模拟设置** → 「最佳路径数据集」组里多了「**导出方式**」：

| 导出方式 | 文件 | 说明 |
|---|---|---|
| **NOAA（IBTrACS）**（默认） | `ibtracs.SIM.<年>.list.v04r01.csv` | 国际通用格式；Excel / pandas / 各种台风工具都能读 |
| **CMA（中国气象局）** | `Best Track <系统日期>-<年>.txt` | 与 1.0/1.1 完全一致的老格式（已发布版本，保持兼容） |

两种格式**共用同一份轨迹数据**、各自落盘、互不覆盖；中途切换格式**不会清空**已记录的轨迹
（一年只在年底写一次文件）。风季模式下与其它可调参数一样被禁用。

### IBTrACS 文件长什么样

- **174 列**宽表、**2 行表头**（第 1 行列名、第 2 行单位，与官方 CSV 一致；pandas 用 `skiprows=2` 读）
- 缺失值写**空**（官方文件写一个空格，我们写空串，pandas 直接读成 NaN）
- 一个风季一个文件；文件内每场台风一段**连续行**（不按时间与其他台风交错）
- 同目录自动生成 `README-SIM.txt` 声明「**这是模拟器生成的数据，不是真实观测**」（只写一次）

| 填什么 | 列 |
|---|---|
| 共享块 | `SID` `SEASON` `NUMBER` `BASIN`(WP) `SUBBASIN`(MM) `NAME` `ISO_TIME` `NATURE` `LAT` `LON` `WMO_WIND` `WMO_PRES` `TRACK_TYPE`(PROVISIONAL) |
| 移速移向 | `STORM_SPEED`（kt）、`STORM_DIR`（°，正北顺时针） |
| 机构块 | **全部留空**（`USA_*` / `TOKYO_*` / `CMA_*` / `HKO_*` …）。我们只有一个模拟结果，不能冒充某个国家机构的观测 |

### 年份与日历

- 游戏内**不显示年份**；导出用**架空年份**，从 `config/simulation.cfg` 的 `[export] initial_year` 起（默认 `0001`）
- 游戏内部仍是 12×30 天，但**导出时映射到现实公历**（大月小月 + 闰年），不会写出 `0002-02-30`
- 跨年台风仍按**生成年份**归到同一个文件，但每行 `ISO_TIME` 用**采样当时的年份**

### 配置（`config/simulation.cfg` 新增 `[export]` 段）

```ini
[export]
initial_year=1        ; 导出的初始 ISO 年份（架空，游戏内不显示年份）
max_wind_kt=300       ; 导出风速上限（kt），只夹导出值，游戏内物理不受影响
fill_usa_agency=false ; true = 额外把强度填进 USA 机构块（给只读 USA_* 的工具用）
```

### 顺手修掉的 bug

- **最佳路径年份索引停滞**：以前 `flush_year()` 写盘成功后会漏掉年份自增，导致第 2 年起所有文件
  仍然记成第 1 年（文件名靠重名后缀区分）。1.1.x 因为没跑过完整一年，一直没暴露。
- 标题画面：「台风模拟」挪进左侧斜向栏、左下角加动态版本号（读 `application/config/version`）。

### 图标方案包（设置 → 预设 → 「方案」）

**2026-11-06 最终版：方案包 = 一个文件夹**（不再用 zip；玩家自己解压放到这里）：

```
<游戏目录>/assets/icons/<方案名>/
├─ index.json          {"version":1,"type":"advanced","object":[{"mainicon.icon.north.c1":"mainicon/c1.ogv"}]}
├─ mainicon/           图标视频/图片
├─ landfall/           登陆特效视频 + 音效
└─ particle/           粒子（eri / note_ts）
```

- **不打包进 pck**（`export_presets.cfg` 的 `exclude_filter` 已排除），启动/打开设置时扫描一次，**不轮询**。
- 下拉顺序：**Default（内建 1.1.1 观感：风圈 + 12 px 小点）→ Advanced default（内建彩色圆盘 + 等级文字）→ 各方案文件夹（按名字排序）**；
  默认选中 **Default**。内建方案不读 `assets/icons/`、不走 `type`。
