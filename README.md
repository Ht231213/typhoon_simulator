# Typhoon — 从 Scratch 移植到 Godot 4

把原来那个 TurboWarp 版台风模拟器（45 个角色 / 2127 个积木）移植到 Godot 4.7 的工程。

## 快速开始

1. 用 `G:\Godot_v4.7.2-stable_win64.exe` 打开 → 导入 `G:\typhoon\project.godot`
2. 按 **F5** 运行

> ⚠ 项目内那份 `Godot_v4.7.2-stable_win64.exe` 是副本（180MB，会被 Godot 文件扫描扫到）。
> 建议移到工程外，日常从 `G:\` 那份启动。
> 另：Godot 4.7.2 在 `--headless` 下退出时会返回 `0xC0000005`，空白场景也一样，是引擎自身的怪癖，不影响运行。

## 时间与节奏

日历基准：**1 个模拟日 = 4 真实秒**（沿用原 Scratch 工程）。天到 31 进月，月到 12 回到 1。

**流速会自动切换**：

| 情况 | 流速 | 说明 |
|---|---|---|
| **有台风在跑** | 4 秒 / 天 | 正常速度，保证台风的增强节奏与原工程一致 |
| **没有台风** | **1 秒 / 天** | 自动加速跳过等待期，天数照常逐日累加、不跳天 |

关键点：物理积分和时钟**共用同一个 `SimClock.time_scale`**，所以改流速**不会**让台风瞬间变强——
台风每模拟日的增量 `dKt/dt` 与流速完全无关。这是移植时最容易搞错的地方。

### 投放冷却

一场台风结束后，需要等待 **5–15 个模拟日**（随机）才能投放下一场。
在空闲加速下这段等待只花 5–15 真实秒。右侧栏会显示倒计时。

### 风季模式

只模拟 **12 个月（360 模拟日）**。结束后：
- 时钟停止、模拟暂停
- 弹出结果面板：台风列表 + 总 ACE
- 成绩写入 ACE 排行榜存档

### ACE 统计规则

⚠ **只有增强到「台风级」（类型 ≥ 0，即 Kt > 33）之后才开始累计 ACE。**
热带扰动 / 热带低压 / 热带风暴阶段一律不计入。

```
ACE += round(Kt² / 100) / 100      ← 仅在 peak_category >= 台风级 时执行
```

### 登陆减弱

台风中心碰到陆地后开始减弱：**−22 节/天**（`Const.LANDFALL_WEAKENING`）。

这个削弱项在代码里必须放在**上限阻尼之后**单独扣（`TyphoonSim._wind_delta_rate`）。
如果放在阻尼之前，会被乘上 `(1 − Kt/170)`：台风 160 kt 时阻尼只剩 0.059，
22 的削弱被压成 1.3，完全盖不过暖池的 +9 节/天正效应 —— 结果就是**登陆后还在加强**。
陆地摩擦来自地形，不该受"环境最大潜在强度"约束。

实测（暖池 31℃）：

| Kt | 阻尼系数 | 不登陆 | 登陆后 |
|---|---|---|---|
| 40 | 0.765 | +16.3 | **−5.7** |
| 90 | 0.471 | +10.0 | **−12.0** |
| 130 | 0.235 | +5.0 | **−17.0** |
| 160 | 0.059 | +1.3 | **−20.7** |

### ESC 暂停菜单

任何场景按 **ESC** 弹出暂停层（`PauseLayer.tscn`），可继续游戏或回主菜单。

实现要点：暂停层本身必须设 `process_mode = ALWAYS`。
原工程的 `esc_handel.gd` 设成了 `WHEN_PAUSED`——**自己负责触发暂停，却要求只在暂停时才处理**，
所以按 ESC 永远没反应。菜单里的按钮也要设 `ALWAYS`，否则 `get_tree().paused = true` 之后点不动。

## 192 个方格放在哪

这是网格的全部位置信息，全在 `scripts/Constants.gd`：

| 内容 | 位置 |
|---|---|
| 192 个海温**数值**（行优先 12×16） | `BASE_SST` 数组 |
| 格子尺寸 | `CELL_W = 1080/16 = 67.5`、`CELL_H = 864/12 = 72` |
| 编号 → 世界矩形 | `cell_rect_world(index)` |
| 编号 → 格中心 | `cell_center_world(index)` |
| 行列 → 编号 | `cell_index_of(row, col)` |
| 世界坐标 → 编号 | `cell_index_from_world(pos)` |
| 实际绘制 | `scripts/OceanField.gd` 的 `_draw()` |

**格子是均匀铺满整张 WPAC.png 的**（16 列 × 12 行），没有偏移或留白。
按 `G` 键可以显示网格线直接目视核对。

陆地判定不用外部掩膜：WPAC.png 里海洋是**统一的深蓝 `(10,10,51)`**（实测多处采样完全一致），
陆地一律满足 `B < R`，所以判据是 `(B - R) < 0.10 → 陆地`，很稳。启动时采样 192 个格子并缓存。

## 移植时最需要知道的一件事

原工程是「**连续积分 + 离散计日**」：强度增速在一个 `forever` 里以 `wait(0.01)` 的节奏积分（≈100 Hz），
而「天」每 4 秒才 +1。

那个 `wait(0.01)` **不是装饰，是数值稳定性的保证**。如果按直觉写成「每天算一次」，风速会直接炸到 546 kt。
本工程用 `_physics_process`（引擎固定 100 Hz）承担这个角色。细节见 `docs/02-移植路线图.md` 第 5 节。
