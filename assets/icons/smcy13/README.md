# 台风图标方案（icon schemes）

> 图标来自用户提供的 **SMCY1.3 图标库**（`mainicon/`）。
> 素材分析见 `docs/研究/06-台风图标素材清点.md`。

## 为什么只要两张图就能动

素材的动画结构非常规整（已逐像素验证）：

| 部位 | 行为 | 结论 |
|---|---|---|
| 内圈白盘（带数字） | **完全静止** | 裁一张静态图 |
| 外圈云系 | **纯刚体旋转**，300 帧 = **5.0 秒**一圈 | 一张静态图 + 引擎旋转 **72°/s** |
| 南北半球 | 只差旋向（北逆时针 / 南顺时针） | **一套贴图通用**，运行时取 ±72 |

所以一档只需要 `xxx_outer.png` + `xxx_inner.png` 两张 256×256 贴图，合计约 75 KB
（原始 mp4 约 10 MB，**省 99%**）。

## 文件约定

```
assets/icons/<方案名>/
├─ scheme.cfg          ← 可选。没有就用内置默认值（转速 72、画布 256、分类映射）
├─ <档位>_outer.png    ← 外圈（黑底已抠成透明，中心挖孔）
├─ <档位>_inner.png    ← 内圈（圆形遮罩，其余透明）
└─ README.md
```

- **两张贴图必须同尺寸**（默认 256×256），运行时同一位置、同尺寸叠放
- 外圈贴图的黑底已经用「亮度 → alpha」处理过 → **普通 alpha 混合**即可，
  不需要加色混合，叠在亮色卫星地图上也看得见
- `scheme.cfg` 的 `[category]` 段把「游戏内强度分类」映射到档位名

## 回退规则（缺东西不会报错、不会空图标）

```
外部目录 <exe目录>/assets/icons/<方案>/   ← 优先（桌面版；web 版没有这一层，跳过）
        ↓ 找不到
内置 res://assets/icons/<方案>/
        ↓ 该档贴图缺失
内置 res://assets/icons/default/ 的同档
        ↓ 还是没有
default 的 generic 档（通用白环，无数字）
```

## 自定义方案怎么做

1. 在**exe 旁边**（或项目的 `assets/` 外置目录）新建 `assets/icons/我的方案/`
2. 放进你自己的 `<档位>_outer.png` / `<档位>_inner.png`（同尺寸即可，不一定是 256）
3. 需要改映射/转速时，复制本目录的 `scheme.cfg` 改一改
4. 游戏里「设置 → 视频 → 图标方案」下拉会自动多出「我的方案」

> 缺哪个档就回退默认方案，**不需要把 22 档全做齐**。

## 本方案包含的档位（22 档，北半球素材，一套通用）

| 档位 key | 说明 | 档位 key | 说明 |
|---|---|---|---|
| `td` | 热带低压 (D) | `c4_plus` | C4+ |
| `ts` | 热带风暴 (S) | `c5` | C5 |
| `ts_plus` | TS+ | `c6` | C6（数字 5）|
| `c1` | C1 | `c6_plus` | C6（数字 6）|
| `c2_minus` | C2- | `c6_max` | C6（数字 7）|
| `c2` | C2 | `db` | 热带扰动 (L) |
| `c3_minus` | C3- | `db_alt` | 扰动变体 (WV) |
| `c3` | C3 | `td_md` | 季风低压 (MD) |
| `c4` | C4 | `ex` / `ex_sd` / `ex_ss` / `ex_ultra` | 温带变性各形态 |
| | | `generic` | 通用型（白环无数字）|

## 已知限制

- **C6 三档的内圈带闪电**：素材里 C6 的闪电铺满圆心，没有静止区（`06` 文档 §2.5）。
  这几档目前游戏用不到（强度分类只到 C5），内圈图里会带一点冻结的闪电；
  以后要用 C6 时应单独处理闪电层。
- 南半球缺 C4 以上素材 → 直接用北半球贴图 + **反向旋转**（视觉上等效）。
- 图标是**黑底抠像**得到的，最暗的辉光边缘会有轻微信息损失；缩到 100 px 显示时看不出来。
